LLM Book Rewriter

Архив .zip, внутри которого находится .txt, .fb2 или .docx
Параметр {text_chunk} автоматически заменяется на фрагмент текста и должен встречаться ровно один раз.
Обработка... Пожалуйста, подождите.

Исправления в тексте

Горячие клавиши: A / Y / Enter / → Принять | R / N / Del / ← Отклонить | ↓ / J Нав. | ↑ / K Пред.
